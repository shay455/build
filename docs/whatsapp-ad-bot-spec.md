# מודעה ב‑98 — איפיון בוט וואטסאפ לייצור קריאייטיב

גרסה 1.0 · ספטמבר 2026 · הגרסה המעוצבת והמלאה: `docs/whatsapp-ad-bot-spec.html`

## הרעיון
בעל עסק שולח תמונת מוצר ומשפט. תוך דקות הוא מקבל 2 קונספטים שונים מאוד של מודעה, כל אחד בשני פורמטים (1:1, 9:16), בעברית נכונה, ובוחר. סרטון 5/10 שניות נוצר רק בפקודה. מחיר: 98 ₪ כולל מע״מ.

## תהליך (שלב 1: המפעיל באמצע)
1. מכירה ותשלום מקדים (ביט / קישור סליקה).
2. הלקוח שולח תמונה, טקסט, לוגו (אופציונלי).
3. המפעיל מעביר לבוט: `לקוח: <שם>` + תמונה + בריף.
4. Claude מנתח ומחזיר קופי + פרומפטים לאישור.
5. ייצור: 2 קונספטים (סטודיו נקי / סצנה אמיתית) → כל אחד בפיד ובסטורי → הלקוח בוחר → "בחר N" → סרטון רק אם מבקשים ("סרטון").
6. בקרה ותיקונים בפקודות (`כותרת: …`, `עוד גרסה`, `סרטון 10`, `בלי סרטון`, `סיום`, `עלויות`).
7. מסירה ללקוח + ארכיון.

## ארכיטקטורה
- ערוץ: WhatsApp Cloud API ישירות ממטא (ללא BSP).
- שרת: Node.js 22 + TypeScript + Fastify; תור BullMQ על Redis.
- מוח: Claude Opus 5 (בריף → JSON מובנה), Haiku 4.5 לניתוב ודירוג.
- תמונה: Nano Banana Pro (Gemini 3 Pro Image) 2K, עריכה לפי תמונת המוצר.
- סרטון: Kling v3 Standard image‑to‑video דרך fal.ai, 5 שנ׳, אודיו.
- טקסט עברי: מצויר בקוד (Sharp + Heebo/Assistant), לא על ידי המודל. כתוביות בסרטון ב‑ffmpeg.
- נתונים: Postgres (Supabase) + Cloudflare R2. טבלת `api_calls` עם עלות בפועל לכל קריאה.
