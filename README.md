# מפתח נכסים

איפיון ופרוטוטייפ לסוכן חיפוש נכסים בישראל: קנייה יד שנייה, שכירות, יחידות דיור
וסטודיו, והשקעה לפי תשואה.

- [`docs/spec-property-search-agent.md`](docs/spec-property-search-agent.md) — מסמך האיפיון המלא
- [`prototype/index.html`](prototype/index.html) — פרוטוטייפ אינטראקטיבי (עמוד יחיד, ללא תלויות)

הפרוטוטייפ מחשב בזמן אמת מס רכישה בחמישה מסלולים, מגבלות מימון של בנק ישראל, תשואה
ברוטו ונטו ועלות חודשית כוללת. הנכסים שבו הם נתוני דוגמה להמחשה ואינם מלאי אמיתי.

מדרגות מס הרכישה נכונות לחוזר מס רכישה 1/2026 של רשות המסים. שיעורי הדירה הנוספת הם
הוראת שעה בתוקף עד 31.12.2026 ויש לאמת הארכה לפני הסתמכות ב-2027.

המסמך והפרוטוטייפ אינם שומה, ייעוץ משפטי או חישוב מס מחייב.
