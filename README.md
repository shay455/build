# מפתח נכסים

סוכן חיפוש נכסים בישראל. מקבל שאלה בשפה חופשית, מסנן ומדרג, ומחזיר כרטיס נכס אחד שבו
כל מה שדרוש להחלטה: המחיר מול חציון האזור, מס הרכישה לפי הפרופיל שלך, ההון העצמי
הנדרש, התשואה, העלות החודשית המלאה, מצב הרישום והדגלים האדומים.

מכסה קנייה יד שנייה, שכירות, יחידות דיור וסטודיו, והשקעה לפי תשואה.

## הרצה

```bash
npm install
npm run dev          # http://localhost:3000
npm test             # 59 בדיקות יחידה
npm run typecheck
npm run build
```

מסד הנתונים הוא SQLite מקומי ב-`data/app.db`, שנוצר ונזרע אוטומטית בהפעלה הראשונה
מ-`src/lib/seed-data.ts`. אפשר לשנות נתיב עם `DATABASE_PATH`. למסד נקי: מחקו את הקובץ.

## API

| נתיב | תיאור |
|---|---|
| `GET /api/search?q=...&profile=...&sort=...` | חיפוש. `q` הוא טקסט חופשי בעברית; פרמטרים מפורשים גוברים על מה שנפרס ממנו |
| `GET /api/properties` | כל הנכסים |
| `POST /api/properties` | הוספת נכס (JSON). מחזיר 422 עם שגיאות פר־שדה |
| `POST /api/import` | ייבוא CSV. שורות תקינות נקלטות, פסולות מדווחות לפי מספר שורה |
| `POST /api/enrich` | שליפת נתוני שוק ממקור וכתיבתם עם פרוביננס. גוף: `{id}` / `{ids}` / ריק לכל המאגר, עם `force` לעקיפת המטמון |

```bash
curl -s --get http://localhost:3000/api/search \
  --data-urlencode 'q=4 חדרים בחיפה עד 2 מיליון עם מעלית וחניה' \
  --data-urlencode 'profile=single'
```

## מקורות נתוני שוק

חציון האזור ועסקאות ההשוואה מגיעים משכבת מקורות מוחלפת (`src/lib/sources/`). כל נתון
נשמר עם `marketSourceId`, `marketStatus`, `marketSampleSize` ו-`marketFetchedAt`,
והכרטיס מציג אותם.

| `MARKET_SOURCE` | מקור | מצב |
|---|---|---|
| ברירת מחדל | `FixtureSource` — עסקאות מתוך מאגר הדוגמה | עובד |
| `nadlan` | `NadlanSource` — נדל״ן של רשות המסים | **לא אומת מול השירות החי** |

אדפטר נדל״ן נכתב מול מבנה הבקשה המתועד, אך **מעולם לא הרצנו אותו מול השירות האמיתי** —
מדיניות הרשת של סביבת הפיתוח חוסמת את `gov.il` ומחזירה 403. יש להריץ אותו מול הנקודה
האמיתית ולתקן את שמות השדות ב-`parseDeals` לפני הסתמכות. הוא לעולם לא זורק חריגה ולעולם
לא ממציא מספר: כל כשל הופך ל-`unavailable`, והמערכת משאירה את הנתונים הקיימים כפי שהם.

### שלושה כללים שנאכפים בקוד

1. **מדגם דק לא מצוטט כאחוז.** מתחת ל-3 עסקאות הסטטוס הוא `thin`, ו-`deltaVsArea`
   מוחזר `null`. הכרטיס מציג „מדגם קטן — N עסקאות” במקום „12% מתחת לחציון”.
2. **מקור שנכשל לא דורס נתונים.** נכס שהמקור לא ידע עליו נשאר עם מה שהיה לו ומדווח
   ב-`skipped` עם סיבה.
3. **המטמון ממופתח לפי מקור.** החלפת `MARKET_SOURCE` לא תגיש מספרים של מקור אחד תחת
   שמו של אחר. תוצאה זמינה נשמרת ליום; כשל נשמר לחמש דקות בלבד.

## החלטות תכן

**גוש/חלקה הוא המפתח הראשי**, לא הכתובת — כתובות בישראל נכתבות בשש צורות, וגוש/חלקה
מזהה חד־ערכית מול נדל״ן, טאבו ו-GovMap. מזהה הישות נגזר ממנו, כך ששתי מודעות לאותו
נכס משני מקורות מתנגשות ביודעין.

**שדות מחושבים אינם נשמרים.** מס רכישה, תשואה, הון עצמי ופער מול האזור תלויים בפרופיל
המשתמש ובמדרגות שמשתנות בחקיקה. שמירה שלהם היא באג מובנה, ולכן הם נגזרים בזמן ריצה
ולא מתקבלים כקלט.

**„לא בדקנו” שונה מ„בדקנו ואין”.** `registryVerified: false` ו-`splitPermit: 'unknown'`
הם ערכים תקפים שמייצרים דגל, ולא שדות ריקים.

**דגל אדום לא מסתיר נכס.** הוא מוריד 25 נקודות מהציון ומסביר למה — ההחלטה נשארת של
המשתמש.

## מדרגות המס

הסכומים הם מהדורת 16.1.2025, שהוקפאה בחוק ההסדרים 2025 ומפורסמת מחדש ללא שינוי
בחוזר מס רכישה 1/2026 של רשות המסים לתקופה 16.1.2025–15.1.2028.

נקודות שנבדקות ב-`tests/tax.test.ts` כי הן הטעויות הנפוצות בשוק:

- **משפר דיור** ממוסה במדרגות דירה יחידה, לא 8% משקל ראשון, בתנאי מכירה בחלון הסטטוטורי.
- **עולה חדש** מעל 20,183,565 ₪ — הקלת תקנה 12א אינה חלה כלל, והחישוב חוזר למדרגות
  הרגילות על מלוא השווי.
- **תקנה 11** — 2,500,000 ₪ הוא מצוק ולא מדרגה: שקל אחד מעל, ו-0.5% חלים על מלוא השווי.
- **דירה נוספת** — שיעורי 8%/10% הם הוראת שעה בתוקף עד **31.12.2026**. יש לאמת הארכה
  לפני הסתמכות עליהם ב-2027. הקבוע `ADDITIONAL_HOME_ORDER_EXPIRES` מסמן זאת בקוד ובממשק.

## מגבלות ידועות

- הנכסים במאגר הם **נתוני דוגמה** ואינם מלאי אמיתי.
- אדפטר נדל״ן לא אומת מול השירות החי (ראו „מקורות נתוני שוק”). ברירת המחדל היא fixtures.
- אין עדיין המרת כתובת לגוש/חלקה (GovMap), ואין שליפת מידע תכנוני או רישומי.
- שכר הדירה האזורי (`areaMedianRent`) עדיין מוזן ידנית ואינו מועשר.
- תקרת הפטור ממס על הכנסה משכירות אינה מגולמת בחישוב התשואה נטו.
- `next` גורר גרסת `postcss` עם התראת audit; אין תיקון בלי שדרוג שובר.

## כתב ויתור

כל תוצרי הכלי נוצרים אוטומטית על ידי מודל בינה מלאכותית, ללא מעורבות, בדיקה או אישור
של שמאי מקרקעין מוסמך, עורך דין או יועץ מס. הפלט אינו שומה, אינו חוות דעת מקצועית
ואינו ייעוץ משפטי או מיסויי. הערכת שווי מחייבת דורשת שמאי מוסמך, עסקת מקרקעין דורשת
עורך דין, וחישוב מס מחייב דורש יועץ מס או רואה חשבון.
