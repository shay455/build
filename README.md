3. חזון, מטרות ומדדי הצלחה
4. פרסונות ותרחישי שימוש
5. דרישות פונקציונליות עם מזהים ותיעדוף MoSCoW
6. ארכיטקטורה טכנית (Claude API, כלי שרת, Managed Agents)
7. עיצוב פרומפטים ואישיות
8. בטיחות, אמון ורגולציה
9. דרישות לא פונקציונליות
10. מודל עסקי ומכסות
11. תוכנית עבודה ואבני דרך
12. סיכונים והחלטות פתוחות
13. מקורות
